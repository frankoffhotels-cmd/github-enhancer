# GitHub Enhancer

Chrome extension that adds Copy and Download buttons to GitHub code blocks and file headers.

## Tech stack

HTML, CSS, JavaScript, Chrome Extensions API (Manifest V3).

## Features

- **Download** button for files.
- **Copy** button for code blocks.

## Install

1. Download or clone this repository.
2. Open `chrome://extensions` in Chrome and enable **Developer mode**.
3. Click **Load unpacked** and select the `github-enhancer` folder.
